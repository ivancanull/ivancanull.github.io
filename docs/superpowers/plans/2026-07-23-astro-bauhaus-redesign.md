# Astro Bauhaus Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the inherited Jekyll template with a small, English-language Astro portfolio that presents Huifan Zhang's research, publications, CV, and availability through a restrained Bauhaus design.

**Architecture:** Astro renders three data-driven routes and a 404 page to static HTML. Three YAML files are parsed and validated through a single content module, then shared by focused components. GitHub Actions runs validation, type checks, tests, and the production build before deploying to GitHub Pages.

**Tech Stack:** Astro, TypeScript, YAML, Zod, Vitest, self-hosted Archivo and IBM Plex Mono, GitHub Pages, GitHub Actions

- [ ] **Step 4: Implement schemas, parsing, cross-file validation, and exports**

Create `src/lib/content.ts`:

```ts
import { parse } from "yaml";
import { z } from "zod";
import siteSource from "../data/site.yml?raw";
import publicationSource from "../data/publications.yml?raw";
import cvSource from "../data/cv.yml?raw";

const linkSchema = z.object({ label: z.string().min(1), url: z.string().min(1) });
const siteSchema = z.object({
  name: z.string().min(1),
  role: z.string().min(1),
  institution: z.string().min(1),
  location: z.string().min(1),
  email: z.string().email(),
  availability: z.string().min(1),
  tagline: z.string().min(1),
  summary: z.string().min(1),
  portrait: z.object({ src: z.string().startsWith("/"), alt: z.string().min(1) }),
  researchAreas: z.array(z.object({ title: z.string().min(1), description: z.string().min(1) })).length(3),
  selectedPublications: z.array(z.string().min(1)).min(1),
  links: z.array(linkSchema).min(1),
});
const publicationSchema = z.object({
  id: z.string().regex(/^[a-z0-9-]+$/),
  title: z.string().min(1),
  authors: z.string().min(1),
  venue: z.string().min(1),
  year: z.number().int().min(1900),
  type: z.enum(["journal", "conference"]),
  summary: z.string().min(1),
  selected: z.boolean().default(false),
  links: z.array(linkSchema).default([]),
});
const cvSchema = z.object({
  education: z.array(z.object({ degree: z.string(), institution: z.string(), period: z.string(), detail: z.string().optional() })),
  projects: z.array(z.object({ title: z.string(), organization: z.string(), period: z.string(), highlights: z.array(z.string()).min(1) })),
  teaching: z.array(z.object({ role: z.string(), course: z.string(), institution: z.string(), period: z.string() })),
  skills: z.record(z.string(), z.array(z.string()).min(1)),
});

export const site = siteSchema.parse(parse(siteSource));
export const publications = z.array(publicationSchema).parse(parse(publicationSource)).sort((a, b) => b.year - a.year);
export const cv = cvSchema.parse(parse(cvSource));

const publicationById = new Map(publications.map((publication) => [publication.id, publication]));
if (publicationById.size !== publications.length) throw new Error("Publication IDs must be unique");
export const selectedPublications = site.selectedPublications.map((id) => {
  const publication = publicationById.get(id);
  if (!publication) throw new Error(`Unknown selected publication: ${id}`);
  return publication;
});
```
